# Security policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/AuroraEnergyResearch/aurora-mcp-resources/security/advisories/new). Do not disclose vulnerabilities in a public issue or discussion.

Include the affected skill or workflow, impact, reproduction steps, and any suggested mitigation. Maintainers will acknowledge the report through the private advisory and coordinate disclosure after a fix is available.
